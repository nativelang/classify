# Contributing to Classify

Write for someone trying Classify for the first time. Start with the task, show a working call and its answer, and introduce each requirement where the reader needs it. [Writing review](.agents/skills/review-classify-writing/SKILL.md)

Keep the reader’s text, categories and expected answer together. Label pseudocode. For a language example, install its dependencies and run the published code before merging.

Use IBM Plex Sans for the Classify name, headings and body text on pages we style, and IBM Plex Mono for code. In the GitHub README, use the wordmark for the title and keep code copyable.

Use a branch and pull request for every change. Merge into `main` after required checks and reviews pass.
